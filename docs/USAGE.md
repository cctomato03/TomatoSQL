# TomatoSQL 使用指南

> 适用于 Windows / macOS / Ubuntu Desktop。下文的截图位置以 Windows 为例，其它平台布局一致。

## 1. 建立连接

### MySQL

1. 点击左侧栏顶部 **`+`**（新建 MySQL 连接），或菜单右键 → 「新建 MySQL 连接」。
2. 填写：连接名称、主机、端口（默认 3306）、用户名、密码；可选默认数据库、字符集、SSL 模式。
   * **SSL 模式**：`禁用` / `优先使用` / `必须使用`。云厂商 MySQL 通常要求「必须使用」。
3. 点击 **测试连接** 确认能连通，再点 **保存**。
4. 在左侧双击连接（或点右侧的插头图标）即可打开。

### SQLite

1. 点击左侧栏 **服务器图标**（新建 SQLite 连接）。
2. 点 **浏览** 选择已有 `.db/.sqlite` 文件；或点 **新建** 指定一个新文件路径（会在首次连接时创建）。
3. 可勾选 **只读打开** 防止误写。
4. 保存后双击连接打开。

> 密码保存在本地，用设备密钥以 AES-256-GCM 加密（`workspace.json` 中是 `enc:v1:...`），不会以明文落盘。

### 分组

* 顶部 **文件夹+** 图标新建分组；分组可再嵌套子分组，可设置颜色标记。
* 右键分组：在此分组新建连接 / 新建子分组 / 重命名 / 删除（删除分组默认把连接移到根目录）。
* 顶部搜索框可按名称、主机、文件路径过滤连接。

## 2. 界面结构

```
顶栏       主题快捷键 · 结构同步 · 云同步 · 设置 · 关于
左栏       分组树 + 连接 + 该连接下的「数据库 → 表/视图/函数/查询/备份」（全部在左栏里）
标签栏     每个连接信息页 / 每张表 / 每个查询窗口一个标签，可同时打开多个连接
内容区     表标签页里有 数据 / 结构 / 索引 / DDL 四个子标签
状态栏     已打开连接数、主题、字号、当前标签
```

**左侧栏里的库/表树**（和 Navicat 一样挂在连接节点下面，打开表数据后依然可见；每一级都比上一级缩进，层级清晰）：

| 操作 | 效果 |
| --- | --- |
| 单击连接 | 仅选中，不展开 |
| 双击连接 | 连接数据库并展开/收起库列表（箭头跟着旋转） |
| 单击数据库 | **仅选中**（高亮），不加载任何元数据 |
| 双击数据库 | **打开**该库（加载表/视图/函数/查询/备份五组）；已打开时双击则关闭 |
| 右键「打开/关闭数据库」 | 打开或关闭该库；关闭会释放元数据，若这个连接上已无其它打开的库，会顺带断开连接（避免长时间占用连接） |
| 单击表 / 视图 | 仅选中 |
| 双击表 / 视图 | **在新标签页打开数据**（每张表一个独立标签，可同时对比多张表） |
| 双击函数 | 打开查询窗口并生成 `SHOW CREATE FUNCTION/PROCEDURE`（MySQL） |
| 双击保存的查询 | 在查询窗口打开该 SQL |
| 双击备份 | 恢复该备份（会弹确认框） |
| 连接行右侧按钮 | 新建查询 / 连接或断开（连接成功后自动展开） |

**数据库下的对象分组**（Navicat 风格，打开数据库后可见 5 组）：

| 分组 | 内容 | 说明 |
| --- | --- | --- |
| 表 | 普通表 | 双击打开数据；右键见下方「表操作菜单」 |
| 视图 | 视图 | 双击查看数据（只读）；右键「新建视图」 |
| 函数 | 存储函数 / 存储过程 | MySQL 来自 `information_schema.ROUTINES`；SQLite 无此概念，显示"无存储函数"；右键「新建函数」 |
| 查询 | 保存的 SQL | 查询窗口点「保存查询」收藏；双击再次打开；右键「新建查询 / 删除查询」 |
| 备份 | SQL 备份文件 | 右键「新建备份」把整库导出为 SQL；双击恢复；右键还可删除或打开所在目录 |

**各层右键菜单**（按层级精简）：

* **连接（已连接）**：新建数据库、运行 SQL 文件…、断开连接、编辑连接、复制连接、删除连接
* **连接（未连接）**：编辑连接、复制连接、删除连接
* **数据库**：打开/关闭数据库、刷新、新建查询、运行 SQL 文件…、导出数据库（仅结构）、导出数据库（结构 + 数据）、删除数据库
* **表**：**表级操作菜单** —— 设计表、刷新表数据、复制表（仅结构 / 结构 + 数据）、转存 SQL 文件（仅结构 / 结构 + 数据）、清空表、截断表、删除表
* **视图 / 函数 / 查询 / 备份**：只保留对应的"新建视图 / 新建函数 / 新建查询 / 新建备份"

**表操作菜单说明**：

| 菜单项 | 说明 |
| --- | --- |
| 设计表 | 打开设计器：可删除列（主键列不可删）、修改列类型与可空性（仅 MySQL）、新增列；保存时生成并执行 `ALTER TABLE` |
| 刷新表数据 | 重新读取表数据；若该表已在标签页打开，标签页会立即刷新 |
| 复制表（仅结构）/（结构 + 数据） | 在当前库中复制成新表，先给出新表名 |
| 转存 SQL 文件（仅结构）/（结构 + 数据） | 把该表导出成一个 `.sql` 文件（含建表语句 / 含数据） |
| 清空表 | `DELETE FROM`：删除所有行，保留自增计数 |
| 截断表 | MySQL 用 `TRUNCATE`（重置自增）；SQLite 用 `DELETE` + 重置 `sqlite_sequence` |
| 删除表 | `DROP TABLE`（有确认框，不可撤销） |

> **「关闭数据库」关闭的是这条数据库服务连接**（整条连接 + 连接池），而不是只收起当前这一个库；
> 关闭后需要重新双击连接才能继续操作。展开/收起单个库请点库名左侧的箭头。

> 「新建数据库」：MySQL 输入库名 + 字符集即可；SQLite 则选一个新文件路径，会创建空库并自动添加一个连接。
> 「删除数据库」会直接 `DROP DATABASE`（有确认框），SQLite 请改用删除文件或移除连接。
> 连接打开后**不会自动展开任何数据库**，需要你自己选择要看哪个库，避免一次性拉取过多元数据。
> 备份文件位置：`<应用数据目录>/backups/<连接ID>/<库名>-<时间戳>.sql`。

> 应用没有欢迎页：启动后主区域是空的，请在左侧栏双击连接开始操作。

## 3. 浏览与编辑数据

* **分页**：底部「每页」可切换 100/200/500/1000/5000 行，并显示总行数与耗时。
* **排序 / 筛选**（点工具条「排序 / 筛选」）：与 Navicat 一样**从下拉列表里选字段**，不用手写 SQL。
  * 排序：可添加多个字段，每个字段选升序/降序，按添加顺序依次生效（等价于 `ORDER BY 字段1 ASC, 字段2 DESC`）。
  * 筛选：可添加多个条件，每行选 **字段 → 操作符 → 值**，多个条件之间用 `AND` / `OR` 连接。
  * 操作符：`=`、`≠`、`>`、`≥`、`<`、`≤`、包含（LIKE）、不包含、开头是、结尾是、在列表中（逗号分隔）、为 NULL、不为 NULL。
  * 改完点 **应用** 生效；**清除** 一次性清空所有排序与筛选。
  * 也可以直接点列头快速按该列排序（等价于设置单字段排序）。
* **编辑**：双击单元格直接改值，改过的单元格会高亮；点 **保存** 批量提交（按主键定位行），**撤销** 放弃修改。
  * 只有存在主键的表可编辑；无主键表为只读（请用查询窗口写 SQL）。
* **新增行**：弹出填值窗口，逐列选择「默认值 / 输入 / NULL」——自增主键自动跳过；必填列留空会提示，不会像以前那样直接执行报错。
* **删除行**：先点选任意单元格选中整行，再点「删除行」（按主键删除，会弹确认框）。
* **NULL** 显示为斜体 `NULL`；二进制列显示为十六进制。
* **结构 / 索引 / DDL** 子标签分别查看列定义、索引与完整建表语句。

## 4. 查询窗口

* 「新建查询」按钮或对象树右上角图标打开；工具条可切换默认数据库。
* 运行：**Ctrl/Cmd + Enter**（选中文本时只运行选中部分）、**F5**、或点「运行」。
* 支持多语句（用 `;` 分隔），每条语句一个「结果 N」标签；被截断时显示「结果已截断」。
* 「导出结果」把当前 SQL 的结果导出为 CSV/JSON/SQL。
* 字号跟随「设置 → SQL 编辑器字号」，行号可在设置里关闭。

## 5. 导入 / 导出

入口：表工具条的「导入 / 导出」按钮、侧栏底部「传输」、或右键连接 → 导入导出。

### 导出

* 格式：**SQL / CSV / JSON**（下拉顺序与默认值都是 SQL 优先，与 Navicat 一致）。
* 选择连接、数据库与表（可多选）；**多表导出 CSV/SQL 时按表名生成多个文件**（`文件名_表名.csv`），JSON 多表则输出 `{ "表名": [ ... ] }`。
* CSV 可配置分隔符（`,` `;` `Tab` `|`）、是否含表头、NULL 的显示文本。
* SQL 可勾选「同时导出建表语句（DDL）」。
* 导出查询结果时，勾选项只剩格式与路径。

### 导入

* 格式：**SQL / CSV / JSON**（按扩展名自动判断，可手动改）。
* 目标表可以是已有表，也可以勾选「表不存在时自动建表」（按数据推断列类型：整数/实数/文本）。
* CSV 选项：首行是列名、空字符串视为 NULL、分隔符；**无表头时按目标表已有列顺序映射**。
* 其它选项：导入前清空目标表、遇到错误跳过该批（`INSERT IGNORE` / `INSERT OR IGNORE`）。
* SQL 脚本导入会逐条执行并汇总成功/失败条数。

## 6. 结构同步 / 数据迁移

入口：顶栏 ⟳ 图标，或右键连接 → 结构同步 / 迁移。

1. 选择 **源连接+库**（基准）与 **目标连接+库**（会被修改）。
2. 点 **比较结构**：列出每张表的状态
   * `仅源库有`（目标缺表）、`有差异`（缺列/类型不同/索引不同）、`一致`、`仅目标有`（不会删除）。
3. 勾选要同步的表与动作：
   * 创建缺失的表、新增缺失的列、创建缺失的索引
   * 复制表数据（可选先清空目标表）
   * 删除并重建同名表（危险操作，会丢目标数据）
4. 点 **执行同步**，下方日志会列出每一步执行的 SQL 与结果。

支持 **MySQL ↔ SQLite 跨引擎迁移**（类型自动映射：整数→INTEGER、小数→REAL、时间→TEXT、文本→TEXT；反向 INTEGER→BIGINT、REAL→DOUBLE、TEXT→LONGTEXT）。

## 7. 主题与字号

**设置 → 外观**：

* 8 套内置主题：番茄浅色、番茄深色、午夜蓝、Nord 极夜、Dracula、Solarized 浅、GitHub 浅、One Dark。点卡片即时生效。
* 顶栏右侧的 🌙/☀️ 按钮可在「浅色/深色」之间快速切换。
* **界面字号** 11–18px：整体文字、行高、控件一起缩放。
* **SQL 编辑器字号** 11–22px：只影响 SQL 编辑区与代码块。
* 所有设置立即写入 `workspace.json`，下次启动自动恢复。

## 8. 云同步（可选）

前提：已部署同步服务（见 `server/README.md`，`docker compose up -d` 即可）。

1. 顶栏 ☁ → 云同步。
2. 服务器地址填 `https://你的域名`（或 `http://IP:8787`），点 **测试**。
3. 用户名 + 登录密码 → **注册并登录**（首次需注册，密码 ≥ 6 位）。
4. 填写 **同步口令**（端到端加密口令，长度尽量 ≥ 16 位）：
   * **上传本地配置到云端**：把连接与分组加密后上传。
   * **智能合并云端**：拉取云端配置，按 `updatedAt` 取较新的记录合并到本地。
   * **从云端覆盖恢复**：用云端配置整体替换本地（会二次确认）。
5. 换机器时：登录同一账号 + 输入**同一个同步口令** → 智能合并/覆盖恢复即可拿回连接与密码。

> 只有「连接与分组」会同步，数据库里的业务数据不会上传。口令忘记则云端密文无法解密，服务端也帮不了。

| 快捷键 | 作用 |

| `Ctrl/Cmd + Enter` | 运行 SQL（有选中则只运行选中） |
| `F5` | 运行 SQL |

## 10. 数据存放与备份

| 平台 | 目录 |
| --- | --- |
| Windows | `%APPDATA%\com.tomatosql.app\` |
| macOS | `~/Library/Application Support/com.tomatosql.app/` |
| Linux | `~/.local/share/com.tomatosql.app/` |

* `workspace.json`：连接、分组、设置（密码为密文）。
* `secret.key`：设备密钥。**迁移机器请用云同步，或直接拷贝后在应用里重新输入密码**（`secret.key` 与新机器不同则旧密文无法解开）。

设置 → 数据与编辑器 里可直接「打开数据目录」和「复制配置 JSON」。
